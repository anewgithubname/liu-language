Liu (流)an executable notation for measure transport

Write flow-matching / diffusion / SVGD experiments the way they are written on a blackboard — as constructions on probability measures. One sentence is the whole language:

flow( field( path ) ) # μ

Straight-line, not Turing-complete

No conditionals, no unbounded loops, no I/O. A program is a finite dataflow DAG — dimensions, capabilities, provenance all check before anything runs. The language itself is the sandbox.

Reproducibility is a contract

program text + seed → bit-identical output (backend pinned, BLAS pinned to one thread). Every figure in this talk regenerates exactly.

Errors are lessons

Every rejection states the mathematical fact violated: draw identity, missing scores, provenance mismatches, maps with no pointwise inverse — each error teaches the construction that fixes it.

Seconds-scale feedback

Single-file C++ interpreter, 2D toy worlds, live-streaming losses and plots in a zero-dependency web playground. Ideas → picture in seconds.

Paths are declared (interpolation formulas), descended (gradient flows of divergences), or coupled & bridged. FM, diffusion, SVGD, OT-CFM, reflow, Schrödinger bridges, drifting models — all the same sentence.
