流Liu
An executable notation for measure transport · one pipeline: flow(field(path)) # μ — with three ways to construct a path: declared by a formula, generated by gradient descent, or (soon) solved as a bridge.
Every figure and every error message on this page is the actual output of the reference interpreter running on the Juzhen CPU backend. A program’s text and seed determine its output bit for bit.

The interpolation formula is part of the program: x_t = t·data + (1−t)·noise. field regresses the conditional-expectation velocity E[ẋ_t | x_t = x] — the unique L² minimizer of the matching loss, and a solution of the continuity equation for this path — and flow integrates it into a map.

program · path_fm.liu
// Flow matching as a declared probability path (spec 10.2):
// the interpolation formula is written in the program itself.
seed 42

noise = gaussian([0, 0], 1)
data  = moons(0.08) ~ 1000

xt = t*data + (1-t)*noise        // each endpoint occurs once: auto-lifted to independent RVs
pt = prob(xt)                     // the law of the process: a probability path
v  = field(pt, estimator=regress(mlp(2 -> 64 -> 64 -> 2)), steps=8000, lr=0.002)
T  = flow(v, steps=50)            // flow(field(prob(xt)))

plot data, (T # noise) ~ 1000
plot (inv(T) # data) ~ 1000, noise ~ 1000   // pullback: should match N(0, I)
plot trajectory of (T # noise) ~ 300

One line of coefficients turns flow matching into diffusion: x_t = √(1−t²)·ε + t·data, a variance-preserving schedule written in the generative direction. Same regression, same pipeline. The probability-flow ODE yields a genuine (pointwise, invertible) map, so the encoder inv(T) comes for free.

program · path_diffusion.liu
// Diffusion as a declared path: change one line of coefficients and
// flow matching becomes diffusion (VP schedule). Written in the
// generative direction (t=0 pure noise, t=1 data), so no reverse needed.
seed 7

e    = gaussian([0, 0], 1)
data = moons(0.08) ~ 2000

xt = sqrt(1 - t*t)*e + t*data
pt = prob(xt)
v  = field(pt, estimator=regress(mlp(2 -> 96 -> 96 -> 2)), steps=8000, lr=0.002)
T  = flow(v, steps=60)

plot data, (T # e) ~ 800
plot trajectory of (T # e) ~ 300
plot (inv(T) # data) ~ 800, e ~ 800   // probability-flow ODE is a genuine Map: encoder for free

The Wasserstein gradient flow of KL(q ‖ p): descent(reverseKL(target), from=…) is an initial-value problem in P(ℝ²). field extracts its velocity with the Nadaraya–Watson estimator (precisely the SVGD update), and flow simulates the interacting particle system. No training — the field is re-estimated at every step.

program · svgd.liu
// SVGD: the Wasserstein gradient flow of reverse KL, in one unified
// pipeline flow(field(descent(...))) (spec 10.2.1).
seed 1

target = 0.7*gaussian([-2, 0], 0.4) or 0.3*gaussian([2, 0], 0.4)

// intent level: the via sugar
Y = target ~ 300 via svgd(kernel=rbf, steps=400, lr=0.8)
plot target ~ 1500, Y
plot trajectory of Y

// mechanism level: descent (an IVP) -> field -> flow, the same pipeline
cloud = uniform([-3, -3], [3, 3]) ~ 300
qt = descent(reverseKL(target), from=cloud)
v  = field(qt, estimator=nw(kernel=rbf))
Z  = flow(v, steps=400, lr=0.8) # cloud
plot target ~ 1500, Z
plot trajectory of Z
