# 用 Liu 写 SBI:cookbook

Simulation-based inference 的全部原料在语言里都有一等对应物;本文整理
三条后验引擎的写法、选路规则、校准手段,以及本仓库实测出的经验教训。
每段代码都与 `examples/` 里的可跑版本逐字一致;所有数字都有 quant
断言,`./interpreter/test.sh` 每次重新验证。

## 0. 角色对应表

| SBI 的概念 | Liu 里的对应物 |
|---|---|
| 先验 p₀(w) | 任意 Distribution:`gaussian([0, 0], 1)` |
| 模拟器 p(y\|w) | **可编程核** `K = kernel(w) { ... }`(§1),或出厂联合(`sine_gaussian` 等) |
| 联合库 {(yⱼ, wⱼ)} | `P = (K \| prior) ~ M` —— 普通 Dataset,y 块在前 |
| 定参跑模拟器 | `(K \| [w]) ~ n` |
| 观测(冻结并可拆) | `(Ys, Ws) = (K \| [w*]) ~ N` —— 两个名字是一张表的行块视图 |
| 后验 | 三条引擎之一(§2),产物是粒子云 Dataset 或摊销核 |

## 1. 写模拟器:`kernel(w) { ... }`

体内是**逐抽取层**语言:名字指抽取块(d×n),算术逐元素带单行广播,
分布自动提升为新抽取,`T # z` 逐抽取应用训练好的传输映射,
`dot(a,b)` 逐抽取内积,`jvp(T,z,v)` 方向导数,`rows(a,lo,hi)` 行切片
(字面界)——矩阵值参数由此可写。末句的值 = 输出 y。

```liu
// 标量玩具:y = sin(2w) + 0.2ε
K = kernel(w) {
    y = sin(2*w) + 0.2*gaussian([0], 1)
}

// 流形论文 Def.1(m=1):训练态的 G 和它的 Jacobian 都是普通体内代码
K = kernel(w) {
    x  = gaussian([0], 1)
    z  = w0 + w*x                        // w0 = inv(G) # Y0,单列 Dataset 进体内变常量块
    y  = G # z
    u  = jvp(G, z, w)
    e  = 0.05*gaussian([0, 0], 1)
    yo = y + e - u*(dot(u, e)/(dot(u, u) + 0.000001))   // 噪声投影到法向
}

// m=2:矩阵参数 W ∈ R^{3×2} 以 6-向量行走,列由 rows 切出
//   z = w0 + rows(w,0,3)*rows(x,0,1) + rows(w,3,6)*rows(x,1,2)
```

samples-only:可编程核无密度无 score(要 score 的路径给指路报错);
`reverseKL((K | prior) ~ M)` 是 likelihood-free 的入口。

## 2. 三条后验引擎

### 2a. 摊销传输(NPSE/FMPE 路线)—— 训练一次,任意观测

条件路径公式 + 条件 flow matching:把噪声传输进**参数块**,**数据块**
作条件;训练只碰联合样本。

```liu
seed 7
noise = gaussian([0], 1)
(d1, th1) = rv(sine_gaussian(2, 0.2))            // 先验+模拟器 = 一次联合抽取
tht = t*th1 + (1-t)*noise                         // 纯抽取插值(裸块)
v = field(prob(tht | d1), estimator=regress(mlp(2 -> 96 -> 96 -> 1)), steps=8000, lr=0.002)
(e0, c0) = rv(linear_gaussian(0, 1))              // 斜率 0 的联合:条件切片 = 基噪声
Tk = flow(v, steps=60) # (e0 | c0)                // 条件映射推核,槽位开着
post = (Tk | [0.5]) ~ 3000                        // 一个网,任意观测
```

- **原理**:摊销后验 = 条件传输映射;条件化沿用唯一语法 `|`,
  在**取律处**附加(`prob(tht | d1)`,2026-07 律门修订——公式里
  只写裸块,行内 `t*(th1|d1)` 是教学报错)。
- **适用**:要对**很多**观测反复推断;参数维度较高(全局函数逼近,
  不付局部窗的维度税——见 §5 的分辨率墙)。
- **成本**:一次网络训练;完整例:`sbi_npse.liu`(三峰质量差 ≤0.052)。

### 2b. 单观测条件 descent(conditional SVGD)—— 零训练,一个观测

钉住即条件化的定理:∇_θ log p(θ|d₀) = ∇_θ log p(θ,d₀)(log p(d₀)
死于 ∇_θ),所以冻结一个"观测块 = d₀、参数块 = 噪声"的联合,让
reverseKL 只移动自由行。

```liu
seed 7
P = sine_gaussian(2, 0.2) ~ 4000                  // 联合模拟抽样(likelihood-free)
(D0, TH0) = rv(couple(gaussian([0.5], 0), gaussian([0], 1))) ~ 1500
qt = descent(reverseKL(P), from=(TH0 | D0))       // 自由行降条件 KL,精确
v  = field(qt, estimator=nw(kernel=rbf))
Post = flow(v, steps=200, lr=0.3) # (TH0 | D0)    // 硬钉自家条件系综
```

- **原理**:钉住块是**观测**,不是云几何——两种条件写法((y|x) 与
  (q|Obs))lower 到**同一个**似然估计器(y-核对参数行的 NW 回归,
  §10.10 似然规则族的锐带宽:按模拟器条件噪声定尺度,不按云散布),
  区别只在聚合语义:(y|x) 取第 c 行为粒子 c 的冻结权重,(q|Obs)
  对 N 个观测行求 log 和。score 目标豁免(钉行处精确求值)。
- **适用**:单个观测、低维参数、要免训练的快后验。
- **守卫**:reverseKL 独有;无 rotation/record=/into=/inv。
- **铺开钉块 = 条件族传输**(2026-07):钉块不取点质量而取**有散布**的
  观测边缘,每个粒子条件在**自己的**钉值上——一次零训练运行完成条件
  分布传输:`#` 返回配对云 (y, x∞),Y-边缘**逐位等于**冻结钉抽取,
  逐切片 = 目标的条件分布(排斥项随之条件化:对数定理的联合 KDE 读法,
  钉通道核按库的似然分辨率 hy 加权;混池排斥实测双败——切片塌缩
  sd 0.16 对 0.351、切片响应过冲 1.89 对 1.096)。闭式对账:
  `cond_family.liu`(斜率 1.12 对 1.096,切片 sd 0.35–0.38)。
  点质量钉块走原混池路径(单切片时混池即条件)。
- 完整例:`sbi_svgd.liu`(盆地质量差 ≤0.05,中心峰 0.598/0.592,
  峰间谷区 0.075 对真值 0.01——quant 双面断言:峰要尖、谷要空);
  用户模拟器版:`sbi_kernel.liu`。

### 2c. N 观测条件 descent(KL 分解)—— 零训练,一批观测

定理:KL[q‖p(·|Y₁..N)] = Σᵢ KL[q‖p(·|Yᵢ)] − (N−1)·KL[q‖p₀] + c。
估计器把可加性装配在**对数权重**里(log λⱼ = Σᵢ log L̂ᵢ(wⱼ),
单似然 = y-核对参数行的 NW 回归),之后每步是对似然加权先验 KDE 的
普通 descent——单吸引、单排斥、单带宽(场级求和在 KDE 下发散或
塌缩,三个失败模式记录在 spec §10.10)。

```liu
seed 7
K = kernel(w) { y = w + 0.5*gaussian([0], 1) }
P  = (K | gaussian([0], 1)) ~ 4000                // 联合库 (y; w)
(Ys, Ws) = (K | [1]) ~ 4                          // 4 个观测,冻结成表
Wc = gaussian([0], 1) ~ 400                       // 待移动的先验云
qt = descent(reverseKL(P), from=(Wc | Ys))        // 条件在观测「集」上
v  = field(qt, estimator=nw(kernel=rbf))
Post = flow(v, steps=150, lr=0.2) # (Wc | Ys)
```

- **原理**:重要性权重级的贝叶斯;似然角色带宽自成规则(k-NN 分位窗
  + Gamma 条件噪声 × KDE 收缩),全确定性。
- **返回形状**:N = 1 时观测集 = 单观测,`#` 返回**钉住联合**(观测行
  平铺在移动后的系综上,可解构;`plot Post` = 观测处的切片竖线,
  `plot P, Post` = 贴库云图——与 (y0|x0) 模式同一契约);N > 1 没有
  "哪一行"可铺,返回**参数系综**(一维边缘用 `plot_signal` 看)。
- **适用**:一批 iid 观测、低维参数;`Obs` 可以是任何 Dataset 列集或
  核联合的解构块。
- **验收**:`sbi_nobs.liu` 对闭式高斯后验——mean 1.105/1.034、
  sd 0.214/0.243;N=1/8/16 扫描全部跟踪。

## 3. 选路指南

| 情形 | 用哪条 |
|---|---|
| 一个观测,d_w ≤ ~3,要快 | 2b 单观测 descent |
| 一批 iid 观测,d_w ≤ ~3 | 2c KL 分解 |
| 很多不同观测要反复问 | 2a 摊销传输 |
| 整族条件分布一次搬运(条件分布传输) | 2b 铺开钉块(`cond_family.liu`;要逐点问切片仍用 2a)|
| d_w 较高(≥ ~4-6) | 2a(核回归似然撞分辨率墙,§5) |
| 长观测序列逐步到达 | 序贯轮(`(K \| 当前云) ~ M` 重模拟库,候选清单)|

## 4. 校准与验收的三个模式(都有现成模板)

1. **闭式对账**(最强):挑一个共轭玩具,quant 从 dump 的观测重算
   闭式后验,对粒子云的 mean/sd —— `sbi_nobs.liu` + `test/quant/sbi_nobs.py`。
2. **植入真值恢复**:已知参数造观测,断言后验找回**可识别泛函**
   (不是参数本身——注意模型的规范等价类/脊)——
   `manifold_local.liu` 的门、`manifold_torus.liu` 的 m=1 门。
3. **墙作对照组**:同一引擎、少信息版本的问题必须**不**开门
   (防估计器偏差假开)——`manifold_local` 的单观测墙、
   `manifold_torus` 的 m=2 墙,quant 双面断言。

## 5. 实测经验规则(每条都有数字与出处)

- **先验是局部性声明**:局部识别要把先验配到邻域尺度——单位先验下
  torus 门全关(\|cos\| 0.52),先验 0.5 时 0.89(`manifold_torus`)。
  机制:库的散布决定两个似然带宽的可用分辨率。
- **分辨率墙**:k-NN 分位窗半径 r 需要 M ≥ k_q/r^d 库抽取;d_w=6 时
  M ~ 10⁵+ 不可行——核回归似然识别不了 m=2 切平面(泄漏有信号、
  张成塌缩;序贯轮买不回)。高维参数请走 2a,或 2b 换
  `estimator=dsm`(神经 score 替核,无窗无带宽;σ 是唯一平滑尺度,
  两网共享;q-网必须热启动——冻结即静态场,实测塌缩)。
- **观测堆叠是陷阱**:把 N 个 iid 观测拼成一个 Nd 维观测再单观测条件
  化,KDE 距离逐槽位比较,吃 1/N! 可交换性惩罚(实测门纹丝不动)——
  用 2c,可加性在权重级。
- **锚点/查询点的拉回敏感度**(用到 inv(G) 锚定时):离流形 σ 的查询
  拉回后偏 ~σ/ρ(各向异性放大,实测 10.2×),但重建的像被往返对消
  保护(≤2σ);切向估计方向免疫、幅度 ×(1.06~1.25);估计与重建用
  同一个锚,幅度偏置自我抵消。
- **下游增益被上游流质量门控**:拉回重建的推论一分离在 G 贴面
  0.054 时消失(比 0.93)、0.034 时 9.4×——先把 G 练好再谈几何增益。
- **复现契约**:同一程序文本 + seed → 输出逐位相同;所有带宽确定性,
  descent 全程零 RNG 消耗;改语句顺序 = 改抽样流。
